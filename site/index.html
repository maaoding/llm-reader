LLM Reader 为复杂非虚构阅读而设计：在原文旁追问、核对引用，并把值得留下的理解保存到本机。

前往 GitHub 首个公开版本准备中
01

导入并阅读

导入无 DRM 的 EPUB 或 UTF-8 TXT，以连续阅读和位置恢复回到正在读的地方。

02

围绕原文提问

选中一段文字即可解释、联系上下文或追问；回答中的引用能回到对应段落。

03

把阅读留在本机

书籍、进度与收藏存放在本地；模型接口由你自行配置，阅读数据不需要账号。
