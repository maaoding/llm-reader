# 官网使用文档验收 · 2026-10-25

## 交付内容

- 新增独立的 `@llm-reader/docs` 工作区包，使用 VitePress 1.6.4。公开内容位于 `docs/manual/`，共 12 个文档页面，覆盖快速开始、阅读、模型、问答、笔记、PDF/OCR、阅读增强、数据与费用、FAQ 和更新日志。
- 官网导航、快速开始按钮、PDF 说明与页脚接入 `/docs/`，README 补充文档入口。文档沿用官网灰蓝配色，提供移动目录、页内目录、浅深色、本地中文搜索和代码复制。
- v1.3.0 发布说明通过 Markdown include 复用仓库原文；协议参考和历史验收记录通过外链访问，不进入公开文档构建目录。旧说明中的版本和入口名称已校正。
- `pnpm site:build` 构建文档，合并首页到 `dist/`，保留 CNAME，生成 `.nojekyll` 与根目录 404，再检查站内链接和站点地图。Pages 工作流检查 PR，合入 `main` 后部署，文档变更也会触发。
