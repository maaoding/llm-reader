# 书库与阅读

普通阅读在本机完成，无需配置模型。

## 导入书籍

在书库点击“导入书籍”，或将文件拖入应用窗口。支持多选，一次最多导入 300 个文件，逐本处理；某一本失败不会阻断其余文件。

| 格式 | 要求与说明 |
| --- | --- |
| EPUB | 无 DRM；固定版式 EPUB 保留原有布局 |
| TXT | UTF-8 编码，单文件不超过 64 MiB |
| PDF | 可直接浏览文字 PDF 或扫描 PDF |
| MOBI / AZW3 | 无 DRM，且本机已安装 [Calibre](https://calibre-ebook.com/)；转换为 EPUB 后导入 |

除 TXT 外，单文件导入上限为 250 MiB。PDF 的 AI 处理另有大小与页数限制，见 [PDF 解析与 OCR](./pdf.md#处理范围)。

导入会将文件复制到应用数据目录；相同文件重复导入会使用已有书籍。单本导入后直接打开，多本导入后显示汇总并留在书库。

## 目录、搜索与摘录

左侧工具栏提供目录、摘录、书内搜索和排版/PDF 工具。再次点击当前入口可收起侧栏。

- **目录**：跳转章节；没有目录的 TXT/EPUB 按实际提取到的结构显示。
- **搜索**：查找当前书中的文字并逐个跳转命中位置。
- **摘录**：选中正文后点击“摘录这段”。摘录会保留高亮，也可从摘录列表返回原文。

自然阅读位置与临时跳转分开保存。通过目录、搜索或引用查看其他位置后，点击“返回阅读处”继续阅读。

## EPUB/TXT 排版

可调整字号、系统字体、行间距、正文宽度、段落间距、首行缩进和对齐。纸张提供默认与护眼偏好，并跟随界面明暗变化。固定版式 EPUB 保留原布局。

TXT 支持标题、强调、列表、引用、代码和表格。在阅读设置的“当前 TXT 显示方式”中，可按书选择：

- **自动识别**：根据内容判断是否使用 Markdown 排版。
- **纯文本**：按原始文本显示。
- **Markdown**：主动按 Markdown 结构排版。

切换只影响显示，原 TXT 文件、原文准备和引用位置保持原有对应关系，无需重新建立索引。HTML、图片和外链以普通文字保留；内容过大或结构无法可靠映射时会提示并回退纯文本。

## PDF 阅读工具

PDF 提供缩放、适合宽度、纸张设置、框选文字和框选图片。

有文字层的 PDF 可框选文字。扫描 PDF 可先直接浏览；要选中文字提问，可以完成逐页 OCR 后切换“识别文字”。也可以直接框选单页图片区域，再用支持图片输入的问答模型提问。两种路线的区别见 [PDF 解析与 OCR](./pdf.md)。

## 恢复阅读

打开书籍会恢复阅读进度。书籍标签可切换和拖拽排序；关闭标签保留书籍数据，重启后可恢复上次打开的书籍和页面。

删除书籍会清理其本机文件、阅读位置、摘录、笔记和相关单书记录。具体保留范围见[数据、隐私与费用](./privacy.md#删除与保留)。
