# 章节笔记与问答集

章节笔记用于整理一本书；问答集用于保存值得回看的回答。两者都可在已有原文的基础上逐步积累。

## 生成章节笔记

1. 在“本书准备”完成原文准备。
2. 为章节笔记选择分析模型，默认使用当前问答配置。
3. 主动开始生成，查看进度；需要时暂停，之后手动继续。
4. 在“章节笔记”中浏览概述、观点、条件、例外、概念与对应来源。

生成会把分节原文发送给所选分析模型，可能产生费用。已完成部分会保留；退出应用后不会自动继续外部任务。

::: tip 原文就绪即可问答
章节笔记是可选增强。尚未生成、部分完成或暂停，都不阻断已有原文的问答。
:::

重新生成笔记只影响笔记。重新准备原文会让依赖旧原文的笔记和语义索引需要重建，请先查看操作提示。

## 归档回答

在回答中点击“归档回答”，将有价值的理解保存到“问答集”。归档保留当轮问题、回答、实际参考原文与来源；使用过联网搜索时，也保留当轮网页资料。

问答集支持跨书搜索和继续追问。继续追问会进入完整对话页；想进行多书比较，可切换到“工作台”。

## 导出 Markdown

在问答集中可导出全部、本书或单条归档；工作台也支持导出会话。导出内容包含对应问答与实际保存的原文摘录、网页来源，便于在其他工具中继续整理。

Markdown 导出用于保存阅读成果，不包含完整书库、服务密钥或所有应用设置，不能代替完整的数据备份。

## 助手设定

在“设置 → 助手设定”管理命名预设，并选择新会话的默认设定。会话输入区可切换预设、临时修改、关闭或另存为新预设。

例如，可以要求助手优先说明论证条件，并在资料不足时说明缺口。设定用于文字和 PDF 图片问答，不用于章节笔记、OCR 或取材规划。

新会话复制创建时的设定。之后修改或删除预设，不会改写已经存在的会话和历史回答。
