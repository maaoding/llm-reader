# 阅读增强与联网搜索

这些功能都可按需添加。只配置问答模型并准备好原文，也可以完成书内问答。

## 先区分用途

| 功能 | 解决什么问题 | 前置条件 |
| --- | --- | --- |
| 按含义查找（Embedding） | 用语义相近的表达寻找书内原文 | 原文就绪，配置 Embedding 模型并建立本书索引 |
| 原文排序（Rerank） | 对检索得到的候选原文重新排序 | 原文就绪，配置并启用 Rerank 服务 |
| 联网搜索 | 补充书籍之外的资料 | 配置搜索服务，且当前会话允许自动联网 |

## 按含义查找

1. 打开“设置 → 阅读增强 → 按含义查找（Embedding）”。
2. 展开配置，填写兼容 Embeddings 的地址、模型和所需密钥。这里需要的是 **Embedding 模型**，不是聊天模型。
3. 测试后保存并启用。
4. 在原文就绪的书籍中打开“本书准备”，建立语义索引。

建索引会把原文分块发送到 Embedding 服务；问答时也可能发送问题和选区。向量保存在本机，无需另装向量数据库。

暂停或退出后，可手动继续建立索引。服务不可用时，问答继续使用关键词检索。更换地址、模型或密钥后需要重建索引；单纯关闭再开启功能可继续使用原索引。

## 原文排序

打开“设置 → 阅读增强 → 原文排序（Rerank）”，填写独立的地址、重排模型与密钥，测试后保存并启用。

例如，兼容服务可使用 `https://api.siliconflow.cn/v1` 和服务实际支持的重排模型。模型是否可用及费用以服务商为准。

有足够书内候选原文时，程序会将问题及候选文本发给重排服务。无需先建立语义索引或生成章节笔记，也不必为开启重排重建已有向量。

超时或失败时会继续使用原检索结果，并在本轮来源详情中显示状态。重排只能改变候选顺序，不能保证模型的回答正确。

## 联网搜索

打开“设置 → 阅读增强 → 联网搜索”，选择服务、填写密钥，测试后保存并启用。

| 服务 | 默认地址 |
| --- | --- |
| Tavily | `https://api.tavily.com` |
| Brave Search | `https://api.search.brave.com/res/v1` |
| Exa | `https://api.exa.ai` |

启用后，新会话默认允许自动联网；输入区的联网按钮可以切换“自动”或“关闭”。旧会话保留原有选择，升级前未设置联网模式的会话保持关闭。

自动模式由问答模型判断是否需要查询，每轮最多搜索一次。切换按钮本身不会发起搜索。搜索接收模型生成的检索词，返回的网页摘录会与本轮资料一起发给问答模型；搜索失败时仍可按已有书内资料回答。

网页引用可查看实际摘录，再主动打开来源。归档和导出保留当轮资料，恢复历史不会重新搜索。

联网适用于文字与整本书问答；PDF 图片问答、章节笔记和 OCR 不使用这项联网搜索。

## 配置与测试

各服务的地址、密钥、请求头和超时独立保存。测试读取当前未保存表单，不自动保存设置，且可能消耗额度。

已有配置的开关可直接启停，关闭会保留配置与已有结果。更换服务地址后需重新填写密钥。发送范围汇总见[数据、隐私与费用](./privacy.md)。
