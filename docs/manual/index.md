# LLM Reader 使用文档

连续阅读，用原文核对每次理解。

这份手册按 Windows x64 **v1.3.0** 的界面编写。你可以先导入书籍直接阅读，再按需要配置 AI 服务。

## 开始使用

| 你想做什么 | 阅读这篇 |
| --- | --- |
| 安装后读第一本书、完成第一次提问 | [快速开始](./getting-started.md) |
| 导入书籍、调整排版、搜索或摘录 | [书库与阅读](./reading.md) |
| 填写 API 地址、密钥和模型 | [配置问答模型](./models.md) |

第一次使用时，按需完成以下准备：

- **直接阅读**：导入 EPUB、UTF-8 TXT 或 PDF 即可，无需账号或模型。
- **选中文字提问**：先[配置问答模型](./models.md)，再选中原文。
- **整本书或多书提问**：配置问答模型，并完成每本书的“本书准备 → 原文准备”。EPUB/TXT 在本机准备；PDF 需要配置解析或 OCR 服务。

章节笔记、按含义查找（Embedding）和原文排序（Rerank）都是可选增强。原文就绪后即可提问，不必先把所有增强服务配置完。
