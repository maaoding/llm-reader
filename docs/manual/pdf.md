# PDF 解析与 OCR

PDF 导入后即可浏览。需要 AI 帮助时，先确定你要问一块图片，还是要在整本 PDF 中检索原文。

## 选择处理方式

| 目标 | 使用方式 | 需要配置 |
| --- | --- | --- |
| 直接阅读 PDF | 导入后打开 | 无 |
| 解释某个图表、公式或单页区域 | 框选图片并确认预览后提问 | 支持图片输入的问答模型 |
| 围绕整本 PDF 提问，保留章节或表格等结构 | 准备原文 | MinerU 或 Docling |
| 识别扫描页，并按页阅读、复制或选中文字提问 | 逐页 OCR，再切换“识别文字” | 视觉模型 OCR、Mistral OCR 或 Unstructured Partition |

复杂论文、表格或公式较多时，优先考虑 MinerU/Docling 的结构化路线。只需逐页文字，或已有兼容视觉模型时，可以先试逐页 OCR。

## 配置 PDF 服务

打开“设置 → 阅读增强 → PDF 解析”，展开“配置详情”，选择服务并填写地址、密钥及所需模型。

| 服务 | 地址示例或说明 |
| --- | --- |
| MinerU 云端 | `https://mineru.net`，填写云端服务密钥 |
| MinerU 本机 | 例如 `http://127.0.0.1:8000`，需先自行部署支持异步任务的服务 |
| Docling | 例如 `http://127.0.0.1:5001`，需先自行部署 Docling Serve |
| 视觉模型 OCR | 独立填写 OpenAI 兼容或 Anthropic 的模型、地址与密钥，模型须支持图片输入 |
| Mistral OCR | 默认 `https://api.mistral.ai/v1`，填写对应密钥 |
| Unstructured Partition | 使用账户提供的 Partition 地址或本机兼容服务地址；不支持 Workflow API |

选择文字提取方式与语言后，测试当前配置，再点击“保存并启用”。启用服务本身不会发送 PDF；打开书籍并主动准备或预览时才处理书中内容。

模型、PDF 服务各自保存凭据，不会自动复制问答密钥。程序不会替你安装本机解析服务。

## 先识别一页

视觉模型 OCR、Mistral OCR 和 Unstructured 支持逐页试识别：

1. 打开 PDF，进入“本书准备”。
2. 选择“先识别一页”，输入 PDF 的实际页码。
3. 对照页面图片和识别文字，检查漏字、阅读顺序、表格和公式。
4. 结果合适后，再决定是否准备全书。

预览可能产生费用。同一书籍与配置下，已有成功结果会优先复用；“重新识别”会再次请求服务。失败时保留上次成功文字，点击重试才重新请求。

预览不改变原有阅读位置或全书准备进度，成功文字可在正式逐页 OCR 时复用。

## 准备全书与恢复

在“本书准备”点击“准备原文”。MinerU/Docling 会接收整份 PDF；逐页 OCR 服务接收待识别页面的图片。

完成后即可问整本书，也可按需生成章节笔记或建立语义索引。

- **逐页 OCR**：已完成页面会缓存；暂停、失败或退出后，由你手动继续。未完成请求可能已被第三方处理，重试可能再次计费。
- **MinerU/Docling**：暂停停止本机等待，远端任务可能继续。再次继续时优先复用已记录的任务或结果。
- **修改配置或重建**：可能需要重新准备；相关笔记和语义索引也可能需要重建，操作前请查看提示。

## 阅读识别文字

逐页 OCR 全书准备完成后，阅读页可切换“识别文字”，逐页阅读、复制和划词提问。引用返回对应 PDF 页核对；“查看原 PDF”可切回原页。

这个视图读取本机已准备的文字，不额外请求 OCR。它不会改变原始 PDF，也不会在扫描图片上生成可选文字层。MinerU/Docling 的整份解析结果暂不提供此逐页阅读视图。

## 处理范围

PDF 解析与 OCR 当前最多处理 **200 MB、600 页**；这与书库导入上限不同。服务商自身还可能有额外限制。

识别文字可能漏字、误读或产生错误。测试样图通过只代表基本请求可用，不能保证书籍识别质量；先试一页，再核对实际原页。

逐页 OCR 按实际 PDF 页码保存文字，不将模型输出当作精确的表格或章节结构。详细接口与恢复边界见仓库中的[服务配置](https://github.com/maaoding/llm-reader/blob/main/docs/provider-configuration.md#pdf-文档处理)及[视觉模型 OCR](https://github.com/maaoding/llm-reader/blob/main/docs/vision-ocr.md)。
