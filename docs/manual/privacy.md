# 数据、隐私与费用

LLM Reader 本地保存书库与阅读记录，无需注册 LLM Reader 账号，不提供同步或遥测。AI 功能使用你配置的服务，按实际操作发送所需资料。

## 本机保存的内容

书籍文件、阅读位置、摘录、原文缓存、章节笔记、草稿、单书会话、问答集和多书工作台保存在本机。

API Key 和自定义请求头通过系统 `safeStorage` 加密保存，设置页不会读回已保存的明文凭据。更换服务地址或协议时，可能需要重新填写凭据。

应用升级继续沿用本机数据，不会自动重新处理书籍或恢复暂停的外部任务。Markdown 导出可以保存阅读成果，但不包含整个书库和全部设置。

## 各功能发送什么

| 功能或服务 | 发送内容 |
| --- | --- |
| 问答模型 | 当轮问题、实际选区/原文、必要背景与历史、助手设定，以及本轮网页摘录 |
| PDF 图片问答 | 你确认的单页裁剪图片和对应问题或追问 |
| 章节分析模型 | 分节原文及必要的中间汇总 |
| Embedding | 建索引时的原文分块，问答时的查询与选区等 |
| Rerank | 问题与候选原文 |
| MinerU / Docling | 主动准备的整份 PDF |
| 视觉模型 OCR / Mistral OCR / Unstructured | 主动预览或准备时的逐页图片 |
| Tavily / Brave Search / Exa | 模型生成的简短检索词与搜索配置 |

只启用 PDF 服务不会立即上传文件。开始预览、准备原文、生成笔记、建索引或提问，才会按相应功能发出请求。

## 费用与暂停

服务费用由所选供应商决定，LLM Reader 不附赠模型、OCR 或搜索额度。连接测试、图片测试、试识别一页以及正式调用都可能消耗额度。

暂停或取消会停止后续调度并终止本机等待，但第三方可能已经接收、处理或计费。逐页 OCR 会保留已完成结果；未完成页重试仍可能再次计费。

退出后，原文处理、章节笔记和语义索引不会自动继续外部调用，需要你手动继续。正在生成的回答也不会跨重启自动续传。

若采用云端服务，请同时了解服务商对上传文件、请求内容和结果的保存政策。本机删除不会自动删除第三方保存的文件或任务。

## 删除与保留

| 操作 | 删除内容 | 保留内容 |
| --- | --- | --- |
| 关闭书籍标签 | 当前标签 | 书籍、阅读位置与已保存记录 |
| 清空单书会话 | 当前会话，取消相关请求 | 其他会话、归档回答与书籍 |
| 删除书籍 | 本机书籍、位置、摘录、原文/索引、笔记、单书会话和单书归档 | 多书工作台的历史回答及保存的来源摘录；该书引用不可再跳转 |
| 删除工作台 | 工作台及其会话，停止相关请求 | 书籍与单书会话 |

删除书籍不可恢复，请先阅读确认提示并导出需要保留的问答。退出时若提示保存失败，可重试；放弃未保存内容后退出会丢失本次尚未保存的修改。
