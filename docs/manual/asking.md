# 提问与核对引用

先[配置问答模型](./models.md)。随后可以围绕选中文字、整本书或几本书提问。

## 选中文字提问

在 EPUB、TXT、有文字层的 PDF 或逐页 OCR 的“识别文字”中选中一段内容，再选择：

- **解释这段**：理解术语、概念或论证。
- **联系上下文**：查看这段内容与实际提供的原文之间的关系。
- **自由提问**：围绕选区写下自己的问题。

未准备原文时，文字问答可以使用选区与有限的当前章节上下文，不代表模型已经读过整本书。想问全书观点时，先完成原文准备。

## 整本书提问

1. 打开“本书准备”，完成“原文准备”。EPUB/TXT 在本机准备，PDF 需要[解析或 OCR 服务](./pdf.md)。
2. 回到阅读助手，将范围切换为“整本书”。
3. 提出具体问题，例如“作者在哪些条件下认为这个方法会失效？请给出原文依据。”

程序会为当轮问题检索书内原文。章节笔记、语义检索和重排可帮助取材，但都不是全书问答的必需条件。

“整本书”表示在这本书中取材，并不表示每轮把完整书籍全部发给模型。没有找到足够原文时，可以缩小问题、补充章节或选中相关段落再问。

## 核对回答

回答的“本次参考原文”展示实际取材范围。展开后查看来源，点击有效引用回到书中对应位置。

- 结合被引用段落的上下文核对，特别留意条件、例外和不同书籍的观点归属。
- 未知或失效引用会标为未验证，不能作为已经定位到原文的依据。
- 当轮没有找到资料，表示本轮依据不足，不能据此认定全书没有相关记载。
- 章节笔记和历史回答可作为背景，不替代当轮原文证据。

## 追问与会话

可继续追问、停止生成、编辑最后一问、重新生成，以及在会话内搜索。Enter 发送，Shift+Enter 换行。

阅读侧栏与完整对话页共用当前会话和草稿。“最近对话”可恢复此前的单书会话。重启后可恢复已保存内容；尚未完成的生成不会自动继续，可按需重新生成。

输入区还可选择[助手设定](./notes.md#助手设定)和[联网模式](./enhancements.md#联网搜索)。联网选择本身不会立即搜索。

## 多书对读

打开“问答集 → 工作台”，创建工作台并选择最多 5 本书。每本参与书籍都需要原文就绪。

可以询问“这几位作者如何定义同一个概念？”或“他们的结论依赖哪些不同前提？”。查看回答时，按来源中的书名分别返回原文核对。

修改选书影响后续问题。重新生成或编辑最后一问时，沿用该轮的书籍范围。工作台会话与阅读区的单书会话分别保存。

需要保留结论和当轮资料时，可[归档或导出](./notes.md#归档回答)。
