# 常见问题

## 需要账号或 API Key 才能阅读吗？

不需要。导入支持的书籍即可直接阅读。使用 AI 问答、章节笔记或其他增强服务时，再配置对应服务与密钥；本机无鉴权接口可以留空密钥。

## 支持 macOS 或 Linux 安装包吗？

目前正式交付 Windows x64 安装包。Linux 可用于源码开发、构建和测试，当前不承诺 Linux 或 macOS 安装包。开发方式见[开发与验证](https://github.com/maaoding/llm-reader/blob/main/docs/development.md)。

## Windows 提示安装程序未签名怎么办？

当前安装包未签名，Windows 可能显示安全提示。请从[官方 GitHub Releases](https://github.com/maaoding/llm-reader/releases/latest)取得安装文件，核对文件信息，再根据系统提示决定是否继续。升级前也可以先导出需要保留的问答。

## 模型连接失败

先检查“设置 → 模型服务”中的当前表单：

1. **地址**：填写服务的 API 地址，确认是否需要 `/v1`，不要填写网站首页。
2. **协议**：Chat Completions 使用 OpenAI 兼容；原生 Messages 使用 Anthropic / Claude。
3. **密钥与模型**：确认该密钥有权限使用所填模型，账户额度充足。
4. **流式响应**：文本测试成功但流式失败时，检查服务或中转是否支持完整的流式回复。
5. **保存与启用**：测试成功后点击“保存并使用”，或将已保存的配置设为当前。

更换地址、协议后需重新填写密钥。服务需要特殊请求头或较长超时时，再调整高级设置。示例见[配置问答模型](./models.md)。

## 原文准备、章节笔记和语义索引必须全部完成吗？

不用。整本书和多书问答需要原文就绪；章节笔记与语义索引都是可选增强。选中文字提问可以先使用选区及有限的当前章节上下文。

EPUB/TXT 原文在本机准备。PDF 的全书问答原文需要配置解析或 OCR 服务。

## 扫描 PDF 无法选中文字

扫描页通常只有图片。可以直接框选单页图片区域，使用支持图片输入的问答模型；也可以完成逐页 OCR，然后切换“识别文字”进行复制或划词提问。

逐页文字视图不会在原 PDF 图片上生成文字层。MinerU/Docling 的整份解析暂不提供该视图。具体步骤见 [PDF 解析与 OCR](./pdf.md)。

## PDF 已经有文字，为什么整本书提问还要准备原文？

阅读器显示的 PDF 文字层用于阅读和选区；全书检索需要准备可检索原文。当前 PDF 原文准备仍通过你选择的解析或 OCR 服务完成。选择“直接使用已有文字”也会调用所选处理服务。

## 准备任务暂停、失败或退出后如何继续？

回到对应书籍的“本书准备”，查看失败原因并手动继续。逐页 OCR 优先复用已完成页面；MinerU/Docling 优先复用已保存任务或结果。

配置变化、远端任务过期或原文重建可能需要重新准备。重建前请查看对章节笔记、索引和费用的影响。退出应用不会自动继续调用外部服务。

## 回答没有引用，或标记为未验证

展开“本次参考原文”，检查本轮实际取材。当前检索可能未找到足够证据，也可能是回答使用了未知引用编号。可以缩小问题、补充章节或选中原文再问。

可点击引用只能帮助定位，不保证回答含义正确。仍需返回原文核对条件与上下文，见[提问与核对引用](./asking.md#核对回答)。

## TXT 排版不符合预期

在阅读设置中找到“当前 TXT 显示方式”，切换为“纯文本”或“Markdown”。选择按书保存，不修改原 TXT，也不要求重新准备原文。

自动识别有内容规模与结构限制，复杂或超限时可能回退纯文本。TXT 需使用 UTF-8 编码。

## MOBI/AZW3 导入失败

确认文件没有 DRM，且本机已安装 [Calibre](https://calibre-ebook.com/)并可使用其转换工具。也可以先自行转换为 EPUB 再导入。

## 更新后数据会丢失吗？能同步到其他设备吗？

正常覆盖升级继续沿用本机书库和配置。应用目前不提供跨设备同步。删除书籍、清空会话和关闭标签的影响不同，见[删除与保留](./privacy.md#删除与保留)。

若出现保存失败提示，先重试并确认保存成功，再退出。Markdown 导出可保存问答成果，不等于完整书库备份。

## 还有问题如何反馈？

在 [GitHub Issues](https://github.com/maaoding/llm-reader/issues) 描述应用版本、Windows 版本、文件格式、使用的协议、操作步骤和错误信息。可附去除私人内容的截图或最小样本；不要附 API Key、自定义认证请求头或个人完整书籍。
