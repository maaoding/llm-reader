## 安装与升级

官方预编译版由 Microsoft Store 更新。后续每个商店包 `X.Y.Z.0` 对应一个 GitHub 源码标签 `vX.Y.Z`。自行构建的版本需手动更新。

从旧 GitHub 安装版切换到商店版时，请先[备份并迁移书库](./faq.md#如何从旧-github-安装版迁移到商店版)。
