# 快速开始

先导入一本 EPUB 或 UTF-8 TXT，可以在本机完成阅读与原文准备。PDF 可直接阅读，整本 PDF 问答所需的服务见 [PDF 解析与 OCR](./pdf.md)。

## 1. 安装

从 [GitHub Releases](https://github.com/maaoding/llm-reader/releases/latest) 下载 Windows x64 安装程序，运行后按提示选择安装目录。

当前安装包未签名，Windows 可能显示安全提示。请核对下载来源与文件；发布页提供对应版本的安装文件及验收说明。

已有版本可打开“设置 → 关于”检查更新。下载完成后点击“重启并安装”；也可退出应用，再运行新安装程序。本机书库和配置继续沿用。

## 2. 导入并阅读

在书库中点击“导入书籍”，或把文件拖入应用窗口。导入后打开书籍即可阅读。

- EPUB/TXT 支持连续阅读，PDF 按连续页面显示。
- 左侧工具栏可以打开目录、搜索和摘录。
- 离开后再次打开，会恢复阅读位置。通过目录或引用临时跳转后，可点击“返回阅读处”。

支持的格式与 TXT Markdown 排版见[书库与阅读](./reading.md)。

## 3. 配置问答模型

打开“设置 → 模型服务”，填写以下内容：

| 字段 | 填什么 |
| --- | --- |
| 协议 | 服务提供的是 OpenAI 兼容接口，还是 Anthropic / Claude 原生接口 |
| Base URL | 服务商提供的 API 地址 |
| API Key | 你在该服务商处取得的密钥；本机无鉴权服务可留空 |
| 模型 | 服务实际支持的模型 ID，可获取列表或手动填写 |

依次测试文本和流式回复，再点击“保存并使用”。只点击“保存配置”会保留配置，之后还需将其设为当前模型。

::: tip 测试与保存
测试使用当前表单，会发送简短请求，可能消耗服务额度。测试通过后仍需保存。地址示例和常见错误见[配置问答模型](./models.md)。
:::

## 4. 选中一段原文提问

回到阅读页，选中一段文字，点击“解释这段”。也可以选择“联系上下文”或“自由提问”。

回答出现在阅读助手中。查看本轮实际参考的原文，点击有效引用回到对应位置，核对解释是否符合原文。资料不足或引用标为未验证时，应结合原文继续判断。

这一步无需先生成章节笔记或建立语义索引。

## 5. 围绕整本书提问

1. 点击阅读页的“本书准备”。
2. 在“原文准备”中开始准备。EPUB/TXT 在本机完成；PDF 需先配置处理服务。
3. 等待原文就绪，回到阅读助手，将提问范围切换为“整本书”。
4. 输入具体问题，例如“作者为这个结论列出了哪些成立条件？”

原文就绪即可提问。章节笔记、Embedding 和 Rerank 都可以之后再添加。

![本书准备：原文已就绪，章节笔记和按含义查找仍为可选任务](/images/book-preparation.png)

*v1.3.0 界面示例，使用自建短文本。原文就绪后，不必等待其余任务完成。*

想保存这次理解，可以点击“归档回答”；想比较几本书，可以在“问答集 → 工作台”选择最多 5 本原文就绪的书。详见[提问与核对引用](./asking.md)和[章节笔记与问答集](./notes.md)。
