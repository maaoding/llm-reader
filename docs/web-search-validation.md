# 单轮联网搜索：实现与验证

2026-09-29 继续本项目中断的 Pi 会话，在已有未提交改动上完成 Tavily 单轮联网问答。保留原来的问答集页面调整和测试文案修正；没有重置工作区、提交、推送或发布，也没有调用用户的真实模型或搜索凭据。

## 使用

在“设置 → 阅读增强 → 联网搜索”填写服务地址和密钥，可测试尚未保存的表单，首次保存后启用。默认地址 `https://api.tavily.com`，默认搜索超时 10 秒。密钥使用主进程的 safeStorage 加密，与问答、章节分析、Embedding、Rerank 和文档处理的凭据分开。

全局启用后，新会话默认“自动联网”；会话内可选“关闭联网”。右侧问答与全屏对话共享此设置，临时会话、最近会话、打开标签和问答集均保存模式。旧记录没有该字段时按关闭处理。解释原文通常不搜索；最新信息、外部例证、事实核实或比较由当前问答模型判断。

空会话也会在退出前保存联网模式，但不会出现在“最近对话”中，也不占用 20 条历史名额。

网页引用显示资料标题，点击可查看实际摘录；“网页资料”折叠区保存检索词、搜索时间和来源。外部浏览器仅能打开该书中由主进程实际提供过的 HTTP(S) 来源，拒绝未记录地址、跨书来源、带账号密码的 URL 和非 HTTP(S) 协议。问答集和 Markdown 导出保留每轮实际发送的来源，读取历史不会重新搜索。

## 实现边界

- 已准备原文的会话在原有取材规划中同时决定是否联网；未准备的文字选区仅在自动联网时增加轻量规划。规划最多 12 秒，规划与搜索均计入问答总超时。
- 一轮最多一次 `/search` 请求，不重试搜索；问答缩减输入重试会复用搜索结果，重新裁剪并生成本轮 `W1…`。旧回答中的 `P…`、`W…` 标记不进入新轮历史。
- 使用 `basic`、最多 5 个结果、`chunks_per_source: 2`，关闭答案、原始正文和图片。服务响应最多 256 KiB，单来源摘录最多 1,200 个 Unicode 码点；不安装 SDK，不抓取网页正文。
- 先保留完整选区，网页输入最多占剩余空间的三分之一，且最多 5,000 个字符（按 JSON 转义后的实际输入计算）。无法容纳摘录时保存搜索记录和明确状态，仅按书内资料回答。
- 网页作为不可信资料，要求回答区分作者原意、网页资料与推断。未知引用显示未验证；摘录中的 HTML 按文字显示。联网失败、空结果或判断失败可回退，取消、删书和退出会终止本地等待。
- 首版用于文字选区和全书问答；PDF 框选图片、笔记生成、独立聊天、多轮搜索和正文抓取不在范围内。SQLite 迁移 21 保存新字段并保留已有服务配置和加密凭据。

## 本地验证

运行环境：Windows，Node `v24.19.0`，pnpm `11.22.0`，Electron `43.3.0`。使用临时书库、自建 TXT 和本机 HTTP 模拟服务，测试密钥均为固定的合成值。

- `tests/unit/backend-web-search.test.ts` 覆盖官方响应的额外字段、请求参数和凭据隔离、URL 安全、Unicode 裁剪、401/429/5xx/重定向、无效及过大响应、响应体超时、取消、单次规划、关闭联网、PDF 排除、总超时、缩减重试复用、预算、迁移、持久化和导出。
- `tests/unit/ui-web-search.test.tsx` 覆盖书内/网页/未知引用、纯文字呈现、显式打开、设置测试与保存、开关、测试结果失效。
- `tests/unit/backend-ipc-import.test.ts` 增加来源打开权限检查，拒绝未记录、跨书、危险协议和不可信窗口调用。
- `tests/e2e/web-search.spec.ts` 实际启动 Electron，覆盖未准备选区、已准备全书、两书并行、失败回退、搜索取消、设置 UI、两种对话表面、来源打开、Markdown 导出、问答集追问与重启恢复，并保存浅色 1440×900 / 深色 940×600 截图。
