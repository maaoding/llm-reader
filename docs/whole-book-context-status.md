- SQLite FTS 全文检索、可选 Embedding 向量和混合检索；向量存入本机 SQLite，无需独立向量数据库服务。
- 独立证据重排配置、一次取材规划、五秒重排回退、证据预算和逐轮引用快照；关联内容只使用剩余名额。

- 原文、笔记、向量任务分别保存状态，支持取消、用户续跑和明确重建；旧数据库、归档与原文引用保持兼容。
