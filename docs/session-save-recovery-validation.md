# 会话保存失败与退出保护验证

记录日期：2026-10-21（UTC）。基于 `1a9133b` 的工作区改动；未推进版本号、构建安装包或发布。

## 行为

- 单书会话、归档续问及会话标签使用待保存队列：只有收到成功结果才确认保存，同一对象串行写入，等待期间合并为最新编辑。失败快照留在内存中，常显提示支持重试。
- 重试使用当前草稿；旧写入的完成或失败不能覆盖新内容。不同书籍可分别保存，单项失败不会阻止其他对象完成。
- 关闭前停止排队和进行中的问答，保留已收到的部分回答为中断状态，并等待单书、归档、标签及多书工作台保存。任一保存失败取消退出，恢复编辑；重试成功不自动关闭窗口。
- 标签恢复未完成时不覆盖已存列表；此时新编辑的归档草稿会阻止退出，需先恢复原标签再保存。
- 清空会话先等待旧写入，再删除旧会话；成功后才清空界面，等待期间该会话暂不能编辑。删除失败保留内容；删除书籍或归档后移除对应待保存记录。
- 主进程按关闭请求编号接受保存结果，忽略过期结果。移除原有 1.5 秒强制关闭；等待超过 15 秒或渲染进程失响应时提供继续等待与明确放弃未保存内容的选择，默认继续等待。
- “重启并安装”同样先保存；安装启动失败时恢复可编辑窗口及关闭保护。

## 验证方法

使用 Linux、Node 24、Electron 44.7.2、Xvfb、D-Bus 和 Xfwm4。每项桌面测试使用隔离临时书库与合成资料，不调用模型或其他外部服务。

新增桌面故障测试在真实 SQLite 表上设置 `BEFORE INSERT` 失败触发器，保留生产 IPC、事务和磁盘写入路径；移除触发器后通过重试及重启核对数据。慢速写入测试仅在测试环境包装原 IPC handler，延迟后仍调用原生产 handler。删除失败与读取失败也只在隔离测试进程注入。
