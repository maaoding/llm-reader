# 视觉模型 OCR

扫描 PDF 没有可提取的文字层时，可使用支持图片输入的模型识别原文，再在书内检索、提问和生成章节笔记。也适用于原有文字提取质量较差的 PDF。本功能在此开发变更中新增，尚未发布安装包。

## 使用

1. 打开“设置 → 阅读增强”，将 PDF 处理服务选为“视觉模型 OCR”。
2. 选择 OpenAI 兼容或 Anthropic / Claude 协议，填写 Base URL、支持图片输入的模型名称及所需 API Key。可以使用与问答相同的服务，也可以分开配置；密钥不会自动从问答设置复制。本机无鉴权接口可留空密钥。
3. “请求适配”默认自动识别官方 OpenCode Go 地址；通过中转使用 Go 时可显式选择 OpenCode Go。语言选择用于识别提示，原文不会被翻译。
4. 点击“测试图片识别”。这会发送一张含 `OCR` 的固定样图，可能消耗额度，不会发送书籍；测试成功后仍需保存设置。
5. 打开 PDF，可先在“本书准备 → 先识别一页”选择实际 PDF 页码，对照图片与识别文字，也可复制原文。默认复用已有结果；“重新识别”会再次请求服务，失败后保留上次结果，点击重试才继续。
6. 点击“准备原文”。逐页显示“已识别 n/N 页”，同一配置下会复用已预览的页面，全部完成后即可选择整本书提问；问答仍使用“模型服务”中配置的模型。
7. 点击回答引用可以返回对应 PDF 页面；保存回答会保留识别原文及页码，便于再次核验。

## 恢复与费用

- 只有主动准备、预览未识别的页面或重新识别时才发送页面，设置测试只发送固定样图。整本 OCR 会跳过已完成的页和同一配置下成功预览的页，其余页面均发送图片，包括已有文字层的页；目前不按文字密度自动跳页。
- 每识别完一页，就将文字写入本机数据库。暂停停止后续请求并中止本机等待；第三方可能已经处理或计费。失败或关闭应用后不会自动继续，用户恢复时从未完成页开始，未完成页可能重复计费。
- 接口、协议、模型、密钥、语言、请求适配或高级请求设置变更后，需要“重新准备原文”，以免混用不同识别结果。同一配置下完整缓存可用于重新分块，不重复识别；明确重建未完成的任务会清除原有进度，但仍可复用当前配置下成功的单页预览。
- 预览结果与整本恢复进度分别保存，重启后仍可用。重新识别只更新本页预览，失败或取消不覆盖上次成功文字；已准备好的原文需“重新准备原文”后应用新预览，其余完整缓存页不会重复请求。
- 重新准备原文会让依赖它的章节笔记和向量需要重建，已保存的回答快照保留。删除书籍取消本机任务并清理对应缓存。
- 图片只用于当前预览和请求，不写入 OCR 缓存；缓存保存识别文字与恢复进度。接口密钥沿用系统 `safeStorage` 加密存储，不进入识别产物。

## 范围与限制

PDF 沿用 200 MB、600 页的处理上限。每页以白底 JPEG 渲染，长边最多 2560 像素，最高按原始尺寸 3 倍渲染；不包含阅读主题、高亮或交互式批注层。单页图片 data URL 最多 600 万字符，识别文本最多 4 万个 UTF-16 代码单元；每本书的预览缓存最多 600 页，每页只保留一份成功文字，换配置后首次识别成功会清理旧预览。整本原始缓存最多 48 MB，规范化结构最多 96 MB，另受现有全文处理上限约束。

单页渲染最多等待 45 秒，识别请求默认最多 90 秒，可在高级设置调整请求超时；外部请求之间让位于正在进行的问答。不自动重试失败页；空响应、超限响应及明确截断、过滤、拒绝的输出不会作为完成页保存。模型返回明确空白页标记时记录该页已完成；整本没有可用文字时提示错误。

OCR 文本可能遗漏、误读或产生幻觉，固定样图通过不代表真实书籍的识别质量。图片内的指令只作为待识别内容，不应执行。程序按实际 PDF 页码建立来源，不采用模型给出的页码、坐标或章节结构；按页分组并给出结构待检查提示，表格和公式保留模型输出的文字表达，不推断跨页表格关系。

原 PDF 保持原样。此功能提供页级引用，不生成可选择的 OCR 文字层，也不增加扫描页划词、框选图片提问或通用看图聊天。

## 接口与验证

OpenAI 协议使用 `POST /v1/chat/completions`，用户消息包含 `text` 和 `image_url`，图片为内联 base64，`detail: high`。Anthropic 协议使用 `POST /v1/messages`、顶层 `system` 及原生 base64 `image` 内容块。两者均使用 `stream: false`，接受版本路径或完整端点。主进程负责请求、鉴权和响应校验；提取窗口只持有当前任务的 PDF 与受限页面请求接口，不持有密钥。拒绝重定向，避免凭据转发。兼容模式的会话标识在同一 OCR 任务的暂停和重启间保留。Mistral OCR、Unstructured Partition 及自定义设置见[服务配置说明](provider-configuration.md)。

- `tests/unit/backend-vision-ocr.test.ts` 覆盖独立设置、样图请求、原文检索与页码、空白页、预览与整本缓存复用、数据库升级、暂停续传、错误与截断、非协作请求取消、删除和配置变更后的迟到响应。
- `tests/unit/book-ocr-preview.test.tsx` 覆盖重试、保留上次结果、复制失败恢复及忽略过期的异步结果。
- `tests/e2e/vision-ocr.spec.ts` 使用真实 PDF.js 渲染及本机模拟视觉接口，覆盖设置、扫描 PDF 识别、全书问答、引用与归档、多页暂停、跨重启恢复、预览复用、剪贴板复制及手动重新识别后的原文重建。
- 本次验证记录见下方；模拟服务不用于评估 OCR 准确率。真实长书识别质量仍需后续验收。
