## 已确认的问题与修改

原实现将原问题、规划关键词和选区直接拼接，再保留前 64 个去重检索词。无章节笔记、Embedding 或 Rerank 时，较长的中文问题会挤掉规划已经给出的英文关键词；前面的长规划词组也能挤掉后面的有效词，造成原文存在却零召回或漏召回。

现在保留同一个 64 词上限，轮流从原问题及各个规划词取词。没有规划词时沿用原顺序；不添加词典、不额外发起规划或外部请求，也不放宽书籍范围。规划提示要求在跨语言问题中提供原文语言关键词。

原有空规划、无效 JSON、请求失败都可回退本地检索；取消会终止流程。它们不等于书中没有答案。回答提示明确区分“本轮依据不足”和“原文明示没有数据”，并根据实际发送的原文在零来源时增加说明。上下文缩减后重新计算该提示，保留网页资料作为外部来源的边界。
