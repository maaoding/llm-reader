## 已知边界

没有明确关联的跨页表格保持独立；没有 cell 页码的来源只能确定整表页范围。未知结构、疑似重复和孤立脚注只提示，不删正文或猜关系。只有用户明确重新准备才为旧版本补充结构；旧归档和旧向量无须自动重建。无有效文字/来源或正文树无法安全解释的服务响应使准备失败，不能宣称全文可检索。

本期不增加图片理解、解析后端、本地 PDF 自动解析、整书 LLM 语义切分、扫描页划词或 OCR 覆盖层。
