# LLM Reader v0.5.0

从一句原文到整本书：这一版带来新的书籍工作台、全书取材、章节笔记浏览，以及能随重启恢复的阅读对话。

## 书籍工作台

- 书库改为紧凑卡片，宽窗口每行三本，支持书名／作者搜索、最近打开排序和继续阅读入口。
- 打开书籍进入概览，集中查看阅读进度、准备状态、已有概述与最近保存的回答；多本书通过顶部标签切换。
- 阅读进度移到标题栏，目录、摘录、搜索、排版／显示及详情集中在左侧图标栏，助手停靠右侧。
- 概览、阅读、章节笔记和完整对话共用阅读状态与会话草稿；回答归档成为独立入口。
- 统一“选中内容／整本书”“摘录这段”“保存回答”“本书准备”等文案，更新应用与网站图标。

## 整本书提问与阅读增强

- 原文准备、章节笔记、按含义查找分别管理状态、进度、暂停、继续与重建。**原文就绪即可整本书提问**，笔记与语义检索均为可选。
- 基于本书原文检索取材，每轮可展开“本次参考原文”核对来源，笔记覆盖与排序详情随回答保存。
- 可选 Embedding 服务帮助查找表达相近的原文，可选 Rerank 服务调整原文排序；服务异常时回退到可用的本地检索结果。
- PDF 原文准备支持 MinerU 本地服务、MinerU 云服务和 Docling Serve，可配置 OCR 与语言，并保留服务提供的章节、表格、脚注、公式和多页来源。
- 章节笔记按真实章节只读浏览，支持部分结果与分页；全书概述、章节汇总和笔记概述支持 Markdown，来源可跳回原文。

## 对话与回答归档

- 新会话默认“整本书”，划词提问切换到“选中内容”；尚缺模型或原文时也可先写草稿。
- 支持编辑最后一轮问题、重新生成、会话内搜索和标签排序。跨书请求最多两个同时进行，更多请求排队，切换书籍不打断回答。
- 每本书自动保存草稿与最近 20 轮已结束问答，重启恢复最近打开的会话标签；修复后台会话漏存、清空后排队请求继续执行、切换范围丢失草稿的问题。
- 回答归档支持 Markdown 预览、跨书搜索、继续追问和 Markdown 导出。

## 下载与升级

- 下载本页的 Windows x64 `setup.exe` 安装程序。安装包未签名，支持选择安装目录。
- 已安装版本可在“设置 → 关于”检查更新，选择下载并重启安装；也可退出应用后运行新安装程序升级。
- 升级沿用本机已有书库、阅读记录、摘录、回答归档与模型配置。不会自动重新处理已有书籍或继续外部服务任务；生成中的回答不跨重启续传。

## 使用说明

- 普通阅读无需模型服务。问答和笔记生成需要自行配置兼容 `/v1/chat/completions` 的模型，按含义查找与原文排序分别需要相应服务，可能产生费用。
- EPUB/TXT 原文准备在本机完成。PDF 文档准备由用户主动开始，会将**整份 PDF** 发送到所选文档服务；应用不内置 OCR 引擎，也不会自动安装外部服务。
- 扫描 PDF 可直接浏览，识别结果用于检索与笔记，不替换原 PDF 页面，也不增加扫描页划词或跨页选区。PDF 文档处理上限为 200 MB、600 页。
- 书籍与阅读记录保存在本机，凭据加密保存。模型、Embedding、Rerank 与文档服务仅按所用功能接收必要输入；不包含 LLM Reader 账号、同步或遥测。
