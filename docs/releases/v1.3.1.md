# LLM Reader v1.3.1

本版集中改善大文档的阅读响应、原文准备与来源定位，并修复 EPUB 阅读区随窗口变化时的尺寸适配。

## 本版变化

- **改善 EPUB 阅读与原文准备**：减少长章节划词、目录定位、脚注关联和原文范围生成中的重复处理，章节切换与正文变化后及时更新定位信息。
- **改善 PDF 划词与导航**：减少长页文字切片、选区上下文、目录进度和框选文字的重复扫描，缩放或重绘后重新建立当前文本层定位。
- **改善 TXT 与 Markdown 搜索**：复用搜索中的字符位置，减少长文本和密集命中的重复统计；Markdown 可见文字继续对应原始 TXT 位置。
- **改善结构化表格处理**：减少重复表头和密集行的字符统计与来源行查找，保留跨页来源、合并单元格和裁剪后的原文范围。
- **完善阅读与回答显示**：减少流式回答、书库和阅读界面的重复处理；修复 EPUB 在窄窗口、侧栏变化和界面缩放后的阅读区尺寸适配。

## 安装与升级

- 从 [v1.3.1 Release](https://github.com/maaoding/llm-reader/releases/tag/v1.3.1) 下载 Windows x64 `LLM-Reader-1.3.1-setup.exe`。安装程序支持选择目录并创建快捷方式；安装包未签名，Windows 可能显示安全提示。
- 已有版本可在“设置 → 关于”检查更新，也可退出应用后手动运行新安装程序。本机书库、阅读记录、摘录、问答集和配置继续沿用；升级不会自动重新处理书籍或恢复暂停的外部任务。
- AI 与联网搜索仍使用你配置的服务，调用可能产生费用。

源码回归、Windows 全新安装、从公开 v1.3.0 覆盖升级及安装包校验值见 [v1.3.1 验收记录](https://github.com/maaoding/llm-reader/blob/v1.3.1/docs/releases/v1.3.1-validation.md)。性能测量使用合成资料，改善幅度随书籍结构与使用场景变化；真实服务验证范围另见该记录。
