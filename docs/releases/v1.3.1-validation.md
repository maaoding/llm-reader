# LLM Reader v1.3.1 发布与验收记录

日期：2026-11-01。本版为阅读性能与兼容性维护版本，包含 v1.3.0 之后的阅读器、渲染、检索和结构化原文处理优化。

当前为发布候选，尚未公开发布。正式版本的完整源码回归、Windows 全新安装及从公开 v1.3.0 覆盖升级正在验收；完成后补充最终提交、工作流、安装包校验值与公开下载复核结果。

此前优化阶段已通过 882 项单元测试及相关桌面场景，另对 1,000 个不规则表格、300 棵 DOM 树和 300 个 PDF 文本模型做过边界对照。这些记录用于说明改动依据，不替代本版最终候选的发布验收。

本轮使用合成书籍、隔离用户资料及本机模拟服务。真实模型、OCR 或文档服务质量没有重新评分。公开状态以 [GitHub Release](https://github.com/maaoding/llm-reader/releases/tag/v1.3.1) 为准；官网在 Release 公开后同步。
