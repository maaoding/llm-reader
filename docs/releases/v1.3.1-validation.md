## 优化依据与边界

优化阶段的兼容性对照覆盖完整新旧输出、Unicode 码点与原始位置、目录顺序、缓存失效和来源裁剪。补充固定种子检查使用 1,000 个不规则表格、300 棵 DOM 树、300 个 PDF 文本模型；15,000 个 DOM 范围、10,968 个目录目标和 30,000 次 PDF 切片对照均通过。

性能基准使用合成资料，并按各阶段分别记录。密集表格、重复表头和超长表头的分节耗时在本机样本下降约 84%～89%；这些数字不代表整本书打开、PDF 服务处理或模型响应速度。多文件 EPUB 的耗时受执行顺序影响，未宣称稳定加速。后续优化需结合代表性真实大书的测量结果。

本轮所有应用回归使用合成书籍、隔离资料与本机模拟服务。真实模型、OCR、文档解析或搜索服务质量没有重新评分。安装包仍未签名。

本地证据位于 `output/release-v1.3.1-20261101/`，包括 `candidate-inputs.json`、`built-output.json`、`test-all.log`、`desktop/results.json`、`cloud-checks.log`、`cloud-desktop.log`、`cloud-package.log`、`ci-installer/`、`verified-assets.json` 与官网预览记录。优化阶段证据独立保留，未将历史结果写成本轮发布回归。
