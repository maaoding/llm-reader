# LLM Reader v1.2.0

本版更新桌面运行时和依赖，延续连续阅读、多书问答与可核对来源的阅读体验；发布验收覆盖全新安装，以及从公开 v1.1.0 覆盖升级后的数据与配置保留。

## 本版变化

- **更新运行时与依赖**：Electron 升级至 44.7.2，更新 React、PDF.js 等依赖；保留现有书库、阅读、问答和本机配置的使用方式。
- **完善开发与回归验证**：迁移至 Vite 8、Vitest 5 和 TypeScript 7 类型检查；修复开发模式下的连接与热更新行为。新增持续集成和可重复执行的 Windows 安装验收。
- **验证覆盖升级**：使用公开 v1.1.0 安装器建立合成资料，再覆盖安装新版本，检查书籍、阅读进度、摘录、问答归档、会话与工作台草稿、本地设置和加密配置的保留。

## 安装与升级

- 下载本页的 Windows x64 `LLM-Reader-1.2.0-setup.exe`。安装程序支持选择目录，并创建快捷方式；安装包未签名，Windows 可能显示安全提示。
- 已有版本可在“设置 → 关于”检查更新，也可退出应用后手动运行新安装程序。本机书库、阅读记录、问答集和配置继续沿用；升级不会自动重新处理书籍或恢复暂停的外部任务。
- AI 与联网搜索仍使用你配置的服务，调用可能产生费用。

完整测试环境、安装包校验值与验证边界见 [v1.2.0 验收记录](https://github.com/maaoding/llm-reader/blob/v1.2.0/docs/releases/v1.2.0-validation.md)。
