# LLM Reader v0.6.0（发布说明草稿）

这一版让扫描 PDF 更容易进入原文问答，也允许直接框选 PDF 页面中的图、公式或表格向当前问答模型提问。全书处理和单页图片提问是两条独立流程，均由用户主动启动。

## PDF 阅读与图片提问

- PDF 阅读页新增“框选图片”：在单页拖出区域并确认预览后，可“解释图片”或输入问题。扫描页和普通 PDF 都可使用，不必先做 OCR。
- 图片问题及后续追问会重新裁剪原 PDF 区域并附图；会话和回答归档只保存页码与区域，不保存裁剪图片。回答可以返回原页，不生成虚假的文字摘录或引用编号。
- 原有“框选文字”保留。左侧入口改为“PDF 工具”，集中显示缩放、纸张和两种框选模式；侧边助手的“最近对话”改为标题栏历史按钮。

## PDF 原文准备

- 可选支持图片输入的 OpenAI 兼容或 Anthropic 模型逐页 OCR，也可配置 Mistral OCR、Unstructured Partition。完成页保存在本机，支持暂停、继续、失败页重试，以及先识别一页并对照原图。
- 逐页 OCR 准备完成后，可在“识别文字”视图按页阅读、复制和划词提问；书内搜索也能查找已保存的识别文字。原 PDF 不变，引用定位到实际 PDF 页码。
- 复杂论文、表格和公式优先建议使用 MinerU 或 Docling 获取文档结构；逐页 OCR 更适合取得页面文字。当前应用按页保存 OCR 结果，不把服务返回的全部表格结构作为精确表格提供。

## 模型与会话

- 问答支持 Anthropic 原生消息协议；文档服务可分别设置地址、认证、请求头、额外参数及超时。模型和文档服务可独立配置。
- 每本书的最近对话可恢复选区、已结束问答和草稿；阅读助手与完整对话页共用会话状态。改进服务测试、准备后搜索和对话恢复的错误处理。

## 升级与使用边界

- 现有书库和归档沿用本机数据；升级不会自动调用模型、重新处理 PDF 或继续暂停的外部任务。
- 图片区域提问需要当前问答模型支持图片输入；不支持时会提示，不会自动切换模型。全书视觉 OCR 仍是可选的逐页文字识别，不是整书多模态理解。
- 普通阅读无需模型服务。使用问答、逐页 OCR 或外部文档服务时，内容会发送至用户配置的服务，可能产生费用。复杂版式和长书的真实识别质量应使用具体模型与 PDF 样本核对。
