# LLM Reader v1.4.0

本版可以在摘录旁记下批注，将当前单书会话保存为 Markdown，也可以将书库备份到另一个本机目录。

## 本版变化

- **整理本书摘录**。在摘录侧栏添加个人批注和标签，搜索摘录或按标签筛选，勾选条目批量导出 Markdown。旧摘录保留原文、高亮和跳转位置，可直接补写批注。
- **复制或导出单书会话**。可复制单轮回答或当前会话，也可将会话另存为 Markdown，随附已记录的书内原文与网页来源。
- **备份和恢复书库**。在“设置 → 备份与恢复”创建本机备份。恢复前可核对时间和记录数量，应用校验通过后切换书库并重启，原书库仍保留在本机。备份目录包含书籍和会话内容，服务配置和凭据需在恢复后重新设置。
- **修复提示遮挡和阅读定位**。保存失败提示会占用独立一行，不再挡住工作台标签和会话操作。调整窗口或关闭 EPUB 目录时，阅读器保留当前章节。已准备好 OCR 识别文字的扫描 PDF 会收起重复的 OCR 提示。

## 安装与升级

- 从 [v1.4.0 Release](https://github.com/maaoding/llm-reader/releases/tag/v1.4.0) 下载 Windows x64 `LLM-Reader-1.4.0-setup.exe`。安装包未签名，Windows 可能显示安全提示。
- 已有版本可在“设置 → 关于”检查更新，也可退出应用后手动运行安装程序。覆盖升级沿用本机书库和配置。

源码回归、安装与升级检查见 [v1.4.0 验收记录](https://github.com/maaoding/llm-reader/blob/v1.4.0/docs/releases/v1.4.0-validation.md)。
