# LLM Reader v1.3.0

本版新增 TXT Markdown 自动排版与按书切换，保留原文及来源位置，并完善取材回退、会话恢复和退出保护。

## 本版变化

- **TXT 自动 Markdown 排版**：在本机识别 TXT 中的 Markdown 结构，显示标题、强调、列表、引用、代码和表格。阅读设置支持按书选择自动识别、纯文本或 Markdown。
- **保留原文与来源位置**：显示方式切换保留原始文件和原文坐标；划词、摘录、搜索与回答引用继续对应原文，已完成的原文准备与索引无需因显示切换重建。
- **改善取材回退**：长问题与规划关键词共享检索预算，保留跨语言关键词；可选书籍选择格式错误时，保留有效取材规划并限定在本轮书籍范围内。未召回原文时明确区分本轮依据不足与书中明确没有数据。
- **完善会话与退出恢复**：改进会话保存失败后的重试、标签恢复、退出前保存，以及更新安装失败后的继续编辑与正常退出。

## 使用与兼容

- TXT 模式入口为打开书籍后的阅读设置“当前 TXT 显示方式”。自动识别使用保守规则，短篇或格式不明确的内容可手动选择 Markdown。
- HTML、图片与链接按普通文本保留，不执行脚本、不自动加载资源或打开外链。过大、过深或无法完整映射的内容回退纯文本。
- 本机书库、阅读位置、摘录、会话、归档回答、工作台及服务配置沿用原有数据。原文准备、章节笔记与可选索引保持独立；升级不会自动调用外部服务。

本轮源码、桌面、Windows 全新安装和从公开 v1.2.0 覆盖升级，以及验证边界见 [v1.3.0 验收记录](v1.3.0-validation.md)。

Windows x64 安装器为 `LLM-Reader-1.3.0-setup.exe`。在“设置 → 关于”可检查更新，也可退出应用后手动安装。安装包未签名；原有本机书库和配置继续沿用，升级不会自动调用外部服务。
