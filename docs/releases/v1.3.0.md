# LLM Reader v1.3.0

本版新增 TXT Markdown 自动排版与按书切换，保留原文及来源位置，并完善取材回退、会话恢复和退出保护。

## 本版变化

- **TXT 自动 Markdown 排版**：支持标题、强调、列表、引用、代码和表格。在阅读设置的“当前 TXT 显示方式”中，可按书选择自动识别、纯文本或 Markdown。
- **保留原文与来源位置**：划词、摘录、搜索和回答引用继续对应原始 TXT；切换显示方式无需重新准备原文或建立索引。HTML、图片和外链仅显示为文字，复杂内容超限时回退纯文本。
- **改善取材回退**：长问题保留跨语言检索关键词，可选书籍选择格式错误时保留有效取材规划。未召回原文时，明确区分本轮依据不足与书中明确没有数据。
- **完善会话与退出恢复**：改进会话保存失败后的重试、标签恢复、退出前保存，以及更新安装失败后的继续编辑与正常退出。

## 安装与升级

- 下载本页的 Windows x64 `LLM-Reader-1.3.0-setup.exe`。安装程序支持选择目录并创建快捷方式；安装包未签名，Windows 可能显示安全提示。
- 已有版本可在“设置 → 关于”检查更新，也可退出应用后手动运行新安装程序。本机书库、阅读记录、摘录、问答集和配置继续沿用；升级不会自动重新处理书籍或恢复暂停的外部任务。
- AI 与联网搜索仍使用你配置的服务，调用可能产生费用。
