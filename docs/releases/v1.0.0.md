# LLM Reader v1.0.0

LLM Reader 进入 1.0：在本机连续阅读 EPUB、TXT 和 PDF，从一句原文到整本书提问，保存有出处的回答，下次打开接着读。普通阅读无需模型服务，AI 功能使用你配置的接口。

## 本版变化

- **中英文界面**：在“设置 → 外观”切换简体中文与 English，选择会保存。默认划词操作名称和提示词跟随界面语言，自定义内容保留。
- **三种联网搜索服务**：支持 Tavily、Brave Search 与 Exa，可配置结果数量、包含／排除域名和高级请求参数。每轮最多搜索一次，使用本轮实际取得的摘录；失败时继续按可用的书内资料回答。
- **问答集布局**：宽窗口采用两列卡片，继续支持跨书搜索、归档追问与 Markdown 导出。
- **安全与 PDF 兼容修复**：升级 Electron、PDF.js 及相关依赖，适配内部链接坐标转换，保留 PDF 脚本、附件、表单及外部跳转限制。
- **更新安装由你确认**：下载完成后保持待安装，普通退出不会触发安装；点击“重启并安装”后才执行。

## 阅读工作台

- 支持 EPUB、UTF-8 TXT 与 PDF；本机安装 Calibre 后还可导入无 DRM 的 MOBI/AZW3。提供批量导入、连续滚动、书内搜索、阅读位置恢复、目录与摘录跳转。
- 选中原文即可解释、联系上下文或自由提问；原文准备完成后可围绕整本书提问。回答保留本轮参考资料，有效引用可回到原文，未知引用标记为未验证。
- 支持可保存的助手设定、章节笔记、PDF 单页框选文字与图片提问，以及通过独立服务完成 PDF 原文准备或逐页 OCR。
- 书籍、进度、摘录、笔记与会话保存在本机；模型及阅读增强凭据加密保存。不包含账号、同步或遥测。

## 安装与升级

- 下载本页的 Windows x64 `LLM-Reader-1.0.0-setup.exe`。安装程序支持选择目录，并创建快捷方式；当前安装包未签名，Windows 可能显示安全提示。
- 已有版本可在“设置 → 关于”检查更新，也可退出应用后手动运行新安装程序。现有本机书库、阅读记录、摘录、问答集和配置沿用；升级不会自动重新处理书籍或恢复暂停的外部任务。
- AI、联网搜索与文档处理需要各自配置的服务，调用可能产生费用。搜索服务接收检索词，问答模型接收本轮所需资料；PDF 处理在你主动开始任务后才发送文件或图片。

本机模拟接口验证不代表真实供应商质量已验证。完整测试、安装升级、文件校验及未覆盖范围见 [v1.0.0 验收记录](https://github.com/maaoding/llm-reader/blob/v1.0.0/docs/releases/v1.0.0-validation.md)。
