# LLM Reader v0.7.0

这一版新增可保存的助手设定与按需联网搜索，并简化阅读助手的输入区。你可以为不同会话选择讲解方式，查看回答实际使用的书内原文与网页摘录，再回到来源核对。

## 助手设定与对话

- “设置 → 助手设定”可保存多套角色与讲解方式，选择新会话的默认值。会话内可切换、临时编辑或关闭，也可另存为预设；后续修改预设不会改写已有会话。
- 助手设定用于文字和 PDF 图片问答，并随历史与问答集保留；章节笔记、OCR 和取材规划不使用它。
- 输入区将联网、助手设定与发送集中为图标按钮，悬停或键盘聚焦可查看提示。长问题自动增高，助手设定在浮层中编辑，侧边助手与完整对话页共享草稿。
- 回答显示生成耗时，输入区可展开查看上轮参考的上下文。已归档回答统一在“问答集”中查看、搜索、继续追问和导出 Markdown。

## 单轮联网搜索

- 在“设置 → 阅读增强 → 联网搜索”配置并启用 Tavily 后，新会话默认由问答模型判断是否需要搜索外部资料，也可在输入区关闭联网；旧会话没有联网设置时保持关闭。
- 每轮最多搜索一次、取得最多 5 个结果。网页引用可查看实际摘录，再主动打开来源；网页资料与书内原文分开标识，未知引用显示为未验证。
- 联网判断或搜索失败时，继续按可用的书内资料回答，并显示本轮状态。会话、问答集和 Markdown 导出保存实际使用的来源，查看历史不会重新搜索。
- 当前用于文字选区与整本书问答，PDF 图片问答、章节笔记和 OCR 不使用联网搜索；不包含多轮搜索或网页正文抓取。

## 阅读与设置修复

- 打开书籍直接进入阅读，整理“笔记”“本书准备”和书籍详情入口，切换工作台页面时保持阅读区宽度稳定。
- 修复 PDF 异步缩放渲染期间滚动位置被覆盖的问题；清理 EPUB 中会触发内容安全策略冲突的 base 元素。
- 统一下拉控件与箭头位置，简化阅读标题栏和服务设置卡片，改善窄窗口中的输入区布局。
- 服务开关使用已保存配置立即生效；测试当前输入不会保存或开始处理书籍。设置栏目间保留草稿，关闭时统一提示未保存修改。

## 升级与使用

- 下载本页的 Windows x64 `LLM-Reader-0.7.0-setup.exe` 安装程序。安装包未签名，支持选择安装目录；已有版本可在“设置 → 关于”检查更新，也可退出应用后运行新安装程序升级。
- 现有书库、阅读记录、摘录、问答集与配置沿用本机数据。升级不会自动重新处理书籍或继续暂停的外部任务。
- 普通阅读无需模型服务。联网搜索需要独立的 Tavily 配置，服务接收模型生成的检索词，网页摘录会发送给问答模型；搜索与模型调用可能产生费用。
