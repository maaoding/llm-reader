# LLM Reader v1.1.0

本版新增多书问答工作台。在“问答集 → 工作台”选择最多 5 本已准备原文的书，比较观点、综合提问，沿回答中的书名与引用回到对应原文。工作台单独保存草稿和历史，下次打开接着聊。

## 本版变化

- **多书对读**：每个工作台可选择最多 5 本书，支持跨书比较与指定书籍追问。回答引用注明书名；修改参与书籍只影响后续问题，历史回答保留当轮来源。
- **独立保存与导出**：工作台与阅读区旁的单书会话分别保存，最多保留 200 轮；支持重命名、停止生成、重新生成、编辑最后一问及 Markdown 导出。删除工作台不删除书籍；删除书籍后，工作台历史回答与引用摘录仍保留，相关原文引用不可跳转。
- **统一对话操作**：工作台使用与阅读助手一致的输入区、联网开关和助手设定，支持长问题自动增高与键盘发送；回答显示模型用量和生成耗时，常用操作集中在回答下方。
- **更清楚的选书与导航**：选书列表支持搜索，已选书籍排在前面；封面与书库保持一致，长书名可展开查看。问答集与工作台共用紧凑顶栏，窄窗口和界面放大时仍可使用主要操作。

## 安装与升级

- 下载本页的 Windows x64 `LLM-Reader-1.1.0-setup.exe`。安装程序支持选择目录，并创建快捷方式；当前安装包未签名，Windows 可能显示安全提示。
- 已有版本可在“设置 → 关于”检查更新，也可退出应用后手动运行新安装程序。现有本机书库、阅读记录、摘录、问答集和配置继续沿用；升级不会自动重新处理书籍或恢复暂停的外部任务。
- 多书提问前，请先为参与书籍完成“本书准备 → 原文准备”。章节笔记和按含义查找仍为可选功能。AI 与联网搜索使用你配置的服务，调用可能产生费用。

测试环境、安装包校验与未覆盖范围见 [v1.1.0 验收记录](https://github.com/maaoding/llm-reader/blob/v1.1.0/docs/releases/v1.1.0-validation.md)。
